# assigning-owner-actions on Hermes

- **Linear calls.** Use the profile's Linear MCP server: list issues by label,
  create the issue with the fields in Steps, and read comments on completed asks.
- **No Linear access.** A profile without a Linear MCP server cannot file the
  issue. Post the ask to the owner in the profile's approval channel, using the
  same four headings, and say that it is not in the inbox view. Do not put it on
  the kanban board: the board is local to one agent and the owner does not read it
  as an inbox.
- **Telling the owner.** One message in the channel the owner reads, with the
  issue link.
- **Approval gates.** If the profile's own instructions gate state-changing
  actions behind an approval message, filing the ask does not replace that gate.
  Follow both.
