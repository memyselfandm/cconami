# Example: the homelab repository's settings

This is how one project, the homelab repository, sets this skill up. It is an
example, not a default.

```markdown
## Operating model

- owner: Mike
- owner-action label: owner-action
- owner inbox view: Waiting on Mike
```

Example titles from that repository:

- `Run the OpenBao policy write for agent-washu-cto`
- `Decide: record Washu's sequencing rulings without a fresh yes?`
- `Approve the SOUL wording for the status report`

An agent there with no Linear access (Gamma) sends her asks through Discord, so they
do not appear in the view.
