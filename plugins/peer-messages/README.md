# peer-messages

A Claude Code mod. It draws a message from another Claude session, agent or
channel as a bordered card headed with the sender's name, and raises a toast when
one arrives. It changes the drawing only; what the model reads is unchanged.

```
/plugin install peer-messages --marketplace memyselfandm/cconami
```

Choose the user scope to have it in every session. It has no settings.

Full behaviour: [../MODS.md](../MODS.md#peer-messages).
