# product

Product skills for shaping work before it reaches the tracker.

```
/plugin install product --marketplace memyselfandm/cconami
```

| Skill | What it does |
|---|---|
| [workshopping-prds](skills/workshopping-prds/) | Runs an interactive, multi-phase PRD workshop; its modes also rank candidate features (RICE, MoSCoW, Kano) and write a one-page product overview |
| [brainstorming-designs](skills/brainstorming-designs/) | Runs design ideation and exploration sessions |
