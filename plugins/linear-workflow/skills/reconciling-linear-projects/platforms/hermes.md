# reconciling-linear-projects on Hermes

- Linear calls: see `pm-context/platforms/hermes.md`.
- **Without a GitHub credential** the profile sees only the pull requests attached to
  tickets in Linear. Steps 1.2 and 1.3 (search by key, by branch) are then skipped; say
  so in the report's first line ("Pull requests read from Linear attachments only") and
  treat every **Behind** verdict as provisional.
- The fixes in step 5 and the moves in step 4 are writes, so they go through the
  profile's approval rules. Gather them into one proposal and ask once, rather than once
  per ticket. The project update in step 6 is part of the same approval.
- Sign the project update with the agent's name, because a Linear OAuth login posts as
  the person who authorised it.
