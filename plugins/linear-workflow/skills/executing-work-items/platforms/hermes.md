# executing-work-items on Hermes

- Hermes agents usually do not hold a code-writing environment of their own. The usual
  route is to hand each ticket to a coding workspace or task runner the profile is
  allowed to start, with the ticket key, branch name and "Done when" as its brief, and
  to track the result in Linear.
- Starting a coding task, claiming a ticket and changing its status are writes: each
  goes through the profile's approval rules. Present the plan from step 3 and treat
  approval of the plan as approval of the claims it lists.
- With no coding route available, stop after step 3 and post the plan as a comment on
  each ticket, so a coding session can pick it up.
- Review and checkpoint hand-offs use the same skills by name, run by whichever agent
  holds them.
